How does it work?

This tool uses the Web Speech API's speechSynthesis interface, a native browser feature available in all modern browsers. Your operating system provides the voices — on Windows you get Microsoft voices, on macOS you get Siri-quality voices, and on Android/iOS you get the device's native TTS engine. Because synthesis happens entirely on your device, no text is ever transmitted to our servers. The optional recording feature captures the audio output from your browser using the Web Audio API and encodes it as a WAV file, also entirely locally.
