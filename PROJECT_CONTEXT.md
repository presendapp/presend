# Presend - Contexte Projet

## Mission
Presend propose des micro-outils IT gratuits, respectueux de la vie privée, sans inscription.

## Stack
- Frontend : HTML/CSS/JS statique, hébergé sur Cloudflare Pages
- Backend : Cloudflare Workers (functions/)
- API : OpenAPI 3.0 (openapi.json)
- SEO : Scripts Python (daily_seo.py, gsc_*.py)
- i18n : 6 langues (fr, en, de, es, ja, pt, ru, hi)

## Structure clé
- tools/ : Outils principaux (HTML)
- functions/api/ : Endpoints API
- functions/_lib/ : Bibliothèques partagées
- blog/ : Articles SEO
- guides/ : Guides pratiques

## Règles
- Pas de tracking utilisateur
- Pas de cookies tiers
- Open source, code lisible
