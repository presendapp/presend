Como funciona?

Esta ferramenta utiliza oInterface SpeechSynthesis da Web Speech API, um recurso nativo do navegador disponível em todos os navegadores modernos. Seu sistema operacional fornece as vozes – no Windows você obtém vozes da Microsoft, no macOS você obtém vozes com qualidade Siri e no Android/iOS você obtém o mecanismo TTS nativo do dispositivo. Como a síntese acontece inteiramente no seu dispositivo, nenhum texto é transmitido aos nossos servidores. O recurso de gravação opcional captura a saída de áudio do seu navegador usando a API Web Audio e a codifica como um arquivo WAV, também totalmente local.
