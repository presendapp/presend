>Wie funktioniert es?

>Dieses Tool verwendet die>SpeechSynthesis-Schnittstelle der Web Speech API, eine native Browserfunktion, die in allen modernen Browsern verfügbar ist. Ihr Betriebssystem stellt die Stimmen bereit – unter Windows erhalten Sie Microsoft-Stimmen, unter macOS Stimmen in Siri-Qualität und unter Android/iOS erhalten Sie die native TTS-Engine des Geräts. Da die Synthese vollständig auf Ihrem Gerät erfolgt, wird niemals Text an unsere Server übertragen. Die optionale Aufnahmefunktion erfasst die Audioausgabe Ihres Browsers mithilfe der Web-Audio-API und kodiert sie als WAV-Datei, ebenfalls vollständig lokal.
