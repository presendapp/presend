Как это работает

Наш генератор паролей использует метод getRandomValues() Web Crypto API, который предоставляет криптографически безопасные случайные числа, полученные из энтропийного пула вашей операционной системы. В отличие от псевдослучайных генераторов, этот метод создает действительно непредсказуемые пароли.
