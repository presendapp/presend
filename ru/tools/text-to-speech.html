Как это работает?

Этот инструмент используетИнтерфейс SpeechSynthesis API Web Speech API, встроенная функция браузера, доступная во всех современных браузерах. Голоса обеспечивает ваша операционная система: в Windows вы получаете голоса Microsoft, в macOS вы получаете голоса качества Siri, а в Android/iOS вы получаете собственный движок TTS устройства. Поскольку синтез происходит исключительно на вашем устройстве, текст никогда не передается на наши серверы. Дополнительная функция записи захватывает аудиовыход вашего браузера с помощью API веб-аудио и кодирует его в файл WAV, также полностью локально.
