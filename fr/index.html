Comment ça marche

Chaque outil de ce site fonctionne entièrement dans votre navigateur. Votre fichier est traité sur votre propre appareil et ne le quitte jamais.

1. Votre fichier
→
2. Traité localement
→
3. Téléchargez le résultat

Aucun serveur ne voit le fichier entre les deux.
