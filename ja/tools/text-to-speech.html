テキスト読み上げ

>テキストを入力または貼り付けると、音声で読み上げられます。ブラウザに組み込まれた音声エンジンを使用します。テキストがデバイスから送信されることはありません。

>どのように機能するのでしょうか?

>このツールは、>Web Speech API の speechSynthesis インターフェイス、最新のすべてのブラウザで利用できるネイティブ ブラウザ機能です。オペレーティング システムが音声を提供します。Windows では Microsoft の音声が、macOS では Siri 品質の音声が、Android/iOS ではデバイスのネイティブ TTS エンジンが提供されます。合成は完全にデバイス上で行われるため、テキストが当社のサーバーに送信されることはありません。オプションの録音機能は、Web Audio API を使用してブラウザからのオーディオ出力をキャプチャし、それを完全にローカルで WAV ファイルとしてエンコードします。
